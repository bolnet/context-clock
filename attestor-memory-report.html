Attestor — memory that doesn’t rot

what context‑clock found

method & honest note

Same harness as the rot benchmark — just add memory

# same loop — but route every memo through Attestor
attestor.add(memo) # tag + graph + vector layers
…
fact = attestor.recall(probe) # retrieve only what’s needed
# probe every 3 turns · 24 turns · recall 100% at every probe
24 turns · probe every 3rd tag + graph + vector retrieval 3 models · 3B→14B ~3,270 vs ~33,187 tokens

Honest note: recall here is real semantic / graph retrieval, not exact-key lookup — Attestor matches the probe against tagged, graph-linked, vector-embedded memos. Same probe, same grading as context-clock’s rot benchmark. The rot was universal; the fix is memory.
